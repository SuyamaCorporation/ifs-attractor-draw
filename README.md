# 16 - IFSアトラクタフラクタル描画

**ビルド日**: 2026-11-03
**カテゴリ**: visual
**slug**: ifs-attractor-draw

## 概要
確率的収縮写像IFS（反復関数系）によるフラクタルアトラクタをCanvas上で動的描画するツール。カオスゲームアルゴリズムで最大50万点を描画し、リアルタイムでパラメータ調整ができる。

## 機能
- バーンズリーのシダ・シェルピンスキー三角形・ドラゴン曲線・フラクタルツリーのプリセット
- 反復回数スライダー（1,000〜500,000）
- 点サイズ・色相スライダーでビジュアルカスタマイズ
- 非同期バッチ描画（UIフリーズなし、進捗%表示）
- PNG保存ボタン
